Only explicit matching retries; no unresolved abandonment, automatic replay or selector retargeting. Late responses cannot confirm another session. Confirmed historical results are separate from current operational state; only confirmed local receipts can be dismissed to begin another action. Storage/locking failure blocks submission.

Visible labels use authoritative business names/numbers and exact decimals. UUIDs remain internal to requests, routing and persisted intent; no technical JSON panel.
